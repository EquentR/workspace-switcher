## Task TASK-08: 按语言偏好提供中文 CLI 帮助和操作消息

### Goal

CLI 进程读取现有语言偏好，用对应语言说明命令、参数、操作结果与错误，同时保持原有调用契约。

预计 2–4 人时。主要触点：CLI Program 启动/帮助/各命令输出、本地化资源及既有设置读取。

### Acceptance

- 每次启动读取同一 language 设置并解析有效语言；显式偏好、跟随系统和英文回退符合 spec，GUI 保存偏好后下一次 CLI 调用生效。
- 帮助及示例解释、缺参数、未知命令、配置不存在、应用/快照/导入/导出/删除/任务栏操作输出支持中英文。
- 后台快捷键服务启动、注册、触发、警告和退出消息支持中英文，但内部热键值和运行行为不变。
- 复用已有本地化门面，不复制第二套语言判定或错误翻译表；已知错误原因处理与 GUI 一致，外部诊断保留。
- 不改命令名、参数名、默认参数、配置字段及各路径原有退出码，不新增 --lang 或设置命令；示例的技术语法保持可执行。
- 用户工作区名、路径、快捷键符号和数量作为参数原样输出，包含中文、大括号时不触发格式错误。

### Dependencies

- 无（首期接口交付作为上述 run 前置条件检查）。

### Test seam

- 实际 CLI 子进程的 --help、未知命令和缺少参数场景，断言 stdout/stderr 与原退出码。先记录英文基线，避免假定现有错误一定返回非零。
- 为测试提供隔离设置上下文；优先使用现有可用入口或内部组合层测试夹具，不新增用户可见 CLI 参数，不读写真实用户 settings.json。
- 复用本地化门面验证涉及窗口/任务栏副作用的消息参数；自动测试不实际恢复、关闭应用或重启 Explorer。

### Checklist

- [ ] 记录现有命令输出/退出码基线，在隔离环境先写语言与兼容行为测试。
- [ ] 接入进程语言初始化及帮助、操作和服务消息资源，覆盖成功与失败分支。
- [ ] 运行针对性 CLI/本地化测试及 Release 编译，记录实际调用结果。
- [ ] 完成双轴审查，原实现代理修复并复验全部未豁免发现。
- [ ] 登记 checkpoint commit、验证和审查证据后标记完成。

## Task TASK-09: 中文 CLI 列表与终端可读性验收

### Goal

用户能在 Windows 终端正常阅读中文表头、工作区列表及服务消息，不发生中文截断、明显错列或乱码。

预计 2–4 人时。主要触点：CLI 列表输出、截断/对齐及输出编码、CLI 验收记录。

### Acceptance

- 列表表头采用名称、图标、窗口数、任务栏固定项、快捷键、最后修改时间；英文表头仍可用，路径和用户内容不翻译。
- 列宽和截断考虑中英文显示宽度及文本元素，不按 string.Length 直接截断中文/代理对或假定 emoji 始终一列。实际 Windows 终端验证，旧终端限制如实记录。
- 中文输出编码适合实际 Windows 终端；重定向到文件后中文可正确读取，不通过改变命令语法解决编码问题。
- 使用无/有配置、长中文名称、中英文混合、emoji、禁用/自动快捷键的列表样例验证可读性。
- TASK-08 的命令/退出码测试与全量测试仍通过，CLI 没有意外应用真实窗口/任务栏副作用。

### Dependencies

- TASK-08。

### Test seam

- 用隔离临时工作区配置调用 list，检查表头、完整文本元素、列内容和重定向编码；断言可观察输出，不测试内部补空格实现。
- 实际 Windows 终端人工检查中英文混合和 emoji 对齐；自动测试不能替代字体/终端渲染验证。

### Checklist

- [ ] 对真实列表输出的截断、内容完整性和重定向编码先写行为测试，再修正显示逻辑。
- [ ] 完成中文表头、显示宽度与编码接入，并验证实际 Windows 终端。
- [ ] 运行相关 CLI 测试、Release 全量构建与测试，记录终端样例及已知限制。
- [ ] 完成本项双轴审查，原实现代理修复并复验全部未豁免发现。
- [ ] 登记 checkpoint commit、验证和审查证据后标记完成。
